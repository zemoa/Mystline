# Mystline 1.3.0

## Fonctionnalités

- Définissez des tâches récurrentes avec les commandes `/r` ou le formulaire « Répéter… » : chaque jour, plusieurs jours de la semaine, tous les N jours ou chaque mois. L’aperçu présente les trois prochaines dates et leurs deadlines éventuelles.
- Le calendrier reste fixe malgré les reports ou les réalisations tardives et anticipées. Cocher une tâche prépare une seule occurrence suivante, sans accumuler les dates manquées. Vous pouvez modifier la répétition, l’arrêter ou annuler le dernier cochage après confirmation.
- Supprimez une tâche depuis le panneau quotidien avec le bouton « Supprimer » ou la touche Suppr. Supprimer l’occurrence à faire arrête sa série et conserve les réalisations ; supprimer une occurrence terminée conserve la suivante.

## Corrections

- Les boutons « Ajouter » et « Répéter… » sont regroupés dans les actions du formulaire d’ajout.

## Documentation et maintenance

- Le README présente les fonctionnalités disponibles. La récurrence est documentée et couverte par des parcours persistés, des tests du contrat IPC et des interactions Vue.

## Compatibilité

Les tâches existantes restent lisibles sans migration au chargement. Les séries ajoutent les métadonnées `@repeat` et `@occurrence` au fichier Markdown ; leur lecture par les versions antérieures n’est pas garantie. Après un cochage dans un éditeur externe, la prochaine occurrence est générée à la prochaine sauvegarde déclenchée dans Mystline.
